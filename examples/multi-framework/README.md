# Multi-Framework Example

Demonstrates that regardless of dialect (HTML, React, Vue, Svelte, or Angular), code lowers into the exact same **Common UI IR** and outputs identical patch structures.

## Expected Behavior
Renders a showcase card highlighting the 4 major reactive frontend paradigms unified under Leveonas.

## Compilation
```bash
npx leveonas check app.lm
npx leveonas compile app.lm
```
